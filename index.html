Gimana cara gabung?
Klik tombol Join Server di atas, nanti kamu diarahkan ke Discord. Gratis, tinggal klik dan masuk.
Gimana cara naik level?
Aktif ngobrol di chat dan nongkrong di voice channel. XP terkumpul otomatis. Ketik .rank di server buat cek posisimu.
Gimana cek coin dan main game?
Ketik .balance buat cek saldo coin. Game yang tersedia antara lain slot, blackjack, tebak angka, tic-tac-toe, dan trivia. Ketik .help buat lihat semua command.
Gimana bikin KTP atau CV Ta'aruf?
Buka kartunya di bagian Coba Langsung, ikuti langkah bergambarnya, lalu klik tombol Buat KTP atau Buat CV di channel-nya.
Kenapa streak aku reset ke 0?
Streak reset kalau kelewat sehari tanpa saling tag dengan temanmu. Kalian berdua harus saling tag setiap hari biar apinya terus nyala.
Ultahku kok gak diucapin bot?
Pastikan kamu sudah daftar lewat tombol Daftar Ulang Tahun di channel Ultah, dengan format tanggal DD-MM-YYYY, contoh 17-08-2005.
Ini server resmi Discord?
Bukan. Game Verse adalah komunitas independen dan tidak berafiliasi dengan Discord.
